# SIWE v4 Migration — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate `metadata-service` from `siwe@^3.0.0` + `@ambire/signature-validator` to `@signinwithethereum/siwe@^4.2.0` (with viem bumped to `^2.49.3`), add caller-asserted `domain` binding with a 1-week grace period, and preserve the existing inline-per-upload + scope/consumption auth model.

**Architecture:** A new injection token `SIWE_CONFIGS` provides a `Map<chainId, SiweConfig>` built via v4's `createViemConfig({ publicClient })` for each supported chain (mainnet + sepolia). `AuthService.verifySiweAndConsume` selects the chain-bound config per request, delegates EIP-1271 / EIP-6492 to v4 + viem natively (Ambire is gone), and asserts the caller's declared `domain` equals the SIWE message's `domain`. The avatar/header upload + delete DTOs gain an optional `domain` field (required in a T+7-day follow-up PR).

**Tech Stack:** NestJS 11 (Fastify adapter), Jest 29 + ts-jest, viem 2.49, `@signinwithethereum/siwe` 4.2, class-validator.

**Spec:** `docs/superpowers/specs/2026-05-20-siwe-v4-migration-design.md`

```ts
import { SiweErrorType } from '@signinwithethereum/siwe';
import { ErrorCodes } from '../common/enums/error-codes.enum';

/**
 * Translate a v4 SiweError into one of our public ErrorCodes.
 * Anything we don't have a specific code for collapses to SIGNATURE_VERIFICATION_FAILED.
 */
export function mapSiweError(err?: { type?: SiweErrorType }): ErrorCodes {
  switch (err?.type) {
    case SiweErrorType.DOMAIN_MISMATCH:        return ErrorCodes.DOMAIN_MISMATCH;
    case SiweErrorType.NONCE_MISMATCH:         return ErrorCodes.NONCE_MISMATCH;
    case SiweErrorType.EXPIRED_MESSAGE:        return ErrorCodes.SIGNATURE_EXPIRED;
    case SiweErrorType.NOT_YET_VALID_MESSAGE:  return ErrorCodes.MESSAGE_NOT_YET_VALID;
    case SiweErrorType.CHAIN_ID_MISMATCH:      return ErrorCodes.INVALID_CHAIN_ID;
    case SiweErrorType.INVALID_ADDRESS:        return ErrorCodes.INVALID_ADDRESS;
    case SiweErrorType.UNABLE_TO_PARSE:        return ErrorCodes.MALFORMED_MESSAGE;
    default:                                   return ErrorCodes.SIGNATURE_VERIFICATION_FAILED;
  }
}
```

```ts
import type { FactoryProvider } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';
import { createPublicClient, http } from 'viem';
import { mainnet, sepolia } from 'viem/chains';
import { createViemConfig, SiweConfig } from '@signinwithethereum/siwe';

/** Injection token: Map<chainId, SiweConfig> built at module init from ALCHEMY_API_KEY. */
export const SIWE_CONFIGS = Symbol('SIWE_CONFIGS');

/** chainId -> SiweConfig bound to that chain's viem PublicClient. */
export type SiweConfigsByChain = Map<number, SiweConfig>;

export const siweConfigsProvider: FactoryProvider<Promise<SiweConfigsByChain>> = {
  provide: SIWE_CONFIGS,
  inject: [ConfigService],
  useFactory: async (configService: ConfigService): Promise<SiweConfigsByChain> => {
    const alchemyApiKey = configService.get<string>('ALCHEMY_API_KEY');
    if (!alchemyApiKey) {
      throw new Error('ALCHEMY_API_KEY environment variable is required');
    }

    const mainnetClient = createPublicClient({
      chain: mainnet,
      transport: http(`https://eth-mainnet.g.alchemy.com/v2/${alchemyApiKey}`),
    });
    const sepoliaClient = createPublicClient({
      chain: sepolia,
      transport: http(`https://eth-sepolia.g.alchemy.com/v2/${alchemyApiKey}`),
    });

    const byChain: SiweConfigsByChain = new Map();
    byChain.set(mainnet.id, await createViemConfig({ publicClient: mainnetClient }));
    byChain.set(sepolia.id, await createViemConfig({ publicClient: sepoliaClient }));
    return byChain;
  },
};
```

```ts
import { Inject, Injectable, UnauthorizedException, ForbiddenException, Logger } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';
import { SiweMessage, generateNonce, isEIP6492Signature } from '@signinwithethereum/siwe';
import { ErrorCodes } from '../common/enums/error-codes.enum';
import { mapSiweError } from './siwe-error.mapper';
import { SIWE_CONFIGS, SiweConfigsByChain } from './siwe.config';

type Scope = 'avatar' | 'header' | 'avatar+header';
type Action = 'avatar' | 'header';

interface NonceRecord {
  nonce: string;
  issuedAt: number;
  expiresAt: number;
  scope: Scope;
  used: { avatar: boolean; header: boolean };
}

interface VerificationParams {
  action: Action;
  message: string;
  signature: string;
  address: string;
  /** Caller-asserted DNS authority. Optional during grace period; required after. */
  domain?: string;
}

@Injectable()
export class AuthService {
  private readonly logger = new Logger(AuthService.name);
  private addressToNonce: Map<string, NonceRecord> = new Map();

  constructor(
    private readonly configService: ConfigService,
    @Inject(SIWE_CONFIGS) private readonly siweConfigs: SiweConfigsByChain,
  ) {
    this.logger.log('AuthService initialized successfully');
  }

  generateNonce(address: string, scope?: Scope): { nonce: string; expiresAt: number } {
    const nonce = generateNonce();
    const issuedAt = Date.now();
    const ttlMs = Number(this.configService.get<number>('SIWE_NONCE_TTL_MS') || 5 * 60 * 1000);
    const expiresAt = issuedAt + ttlMs;
    const effectiveScope: Scope = scope ?? 'avatar+header';
    this.addressToNonce.set(address.toLowerCase(), {
      nonce,
      issuedAt,
      expiresAt,
      scope: effectiveScope,
      used: { avatar: false, header: false },
    });
    return { nonce, expiresAt };
  }

  private configFor(chainId: number) {
    const config = this.siweConfigs.get(chainId);
    if (!config) {
      this.logger.warn(`No SiweConfig for chainId ${chainId}; falling back to mainnet`);
      return this.siweConfigs.get(1);
    }
    return config;
  }

  private isDomainRequired(): boolean {
    return this.configService.get<string>('SIWE_DOMAIN_REQUIRED') === 'true';
  }

  private getAllowedChainIds(): number[] {
    return (this.configService.get<string>('SIWE_ALLOWED_CHAIN_IDS') || '1,11155111')
      .split(',')
      .map((v) => v.trim())
      .filter(Boolean)
      .map((v) => Number(v))
      .filter((v) => Number.isFinite(v));
  }

  async verifySiweAndConsume(params: VerificationParams): Promise<{ address: string }> {
    const { action, message, signature, address, domain: providedDomain } = params;
    const lower = address.toLowerCase();
    this.logger.log(`siwe.verify.attempt ${JSON.stringify({ address: lower, assertedDomain: providedDomain ?? null })}`);

    const record = this.addressToNonce.get(lower);
    if (!record) {
      throw new UnauthorizedException({ code: ErrorCodes.NONCE_NOT_FOUND, details: { address } });
    }

    let siwe: SiweMessage;
    try {
      siwe = new SiweMessage(message);
    } catch {
      throw new UnauthorizedException({ code: ErrorCodes.MALFORMED_MESSAGE });
    }

    // Domain handling (grace-period aware)
    let effectiveDomain: string;
    if (providedDomain) {
      if (siwe.domain !== providedDomain) {
        throw new UnauthorizedException({
          code: ErrorCodes.DOMAIN_MISMATCH,
          details: { assertedDomain: providedDomain, siweDomain: siwe.domain },
        });
      }
      effectiveDomain = providedDomain;
    } else if (this.isDomainRequired()) {
      throw new UnauthorizedException({ code: ErrorCodes.MISSING_DOMAIN });
    } else {
      this.logger.warn(
        `siwe.domain.deprecated ${JSON.stringify({ address: lower, siweDomain: siwe.domain })}`,
      );
      effectiveDomain = siwe.domain; // graceful no-op binding during grace period
    }

    // Chain allowlist
    const chainId = Number(siwe.chainId);
    const allowedChainIds = this.getAllowedChainIds();
    if (allowedChainIds.length > 0 && !allowedChainIds.includes(chainId)) {
      throw new UnauthorizedException({ code: ErrorCodes.INVALID_CHAIN_ID, details: { chainId } });
    }

    // v4 verify
    const { success, data, error } = await siwe.verify(
      { signature, domain: effectiveDomain, nonce: record.nonce, chainId },
      { config: this.configFor(chainId), suppressExceptions: true },
    );
    if (!success || !data) {
      throw new UnauthorizedException({
        code: mapSiweError(error),
        details: { siweErrorType: error?.type },
      });
    }

    // Defence-in-depth address cross-check
    if (data.address.toLowerCase() !== lower) {
      throw new UnauthorizedException({
        code: ErrorCodes.ADDRESS_MISMATCH,
        details: { recovered: data.address },
      });
    }

    // App-specific nonce TTL
    if (Date.now() > record.expiresAt) {
      this.addressToNonce.delete(lower);
      throw new UnauthorizedException({ code: ErrorCodes.SIGNATURE_EXPIRED });
    }

    // Scope + consumption (unchanged from previous behaviour)
    const scope = record.scope;
    if (action === 'avatar') {
      if (scope === 'header' || record.used.avatar) {
        throw new ForbiddenException({ code: ErrorCodes.UNAUTHORIZED });
      }
      record.used.avatar = true;
    } else if (action === 'header') {
      if (scope === 'avatar' || record.used.header) {
        throw new ForbiddenException({ code: ErrorCodes.UNAUTHORIZED });
      }
      record.used.header = true;
    }

    const bothConsumed = record.used.avatar && record.used.header;
    if (bothConsumed || Date.now() > record.expiresAt) {
      this.addressToNonce.delete(lower);
    } else {
      this.addressToNonce.set(lower, record);
    }

    const signatureType = isEIP6492Signature(signature) ? 'eip6492' : 'standard';
    this.logger.log(
      `siwe.verify.success ${JSON.stringify({ address: lower, domain: effectiveDomain, chainId, signatureType })}`,
    );

    return { address: lower };
  }
}
```

```ts
 * A tiny EOA-only SiweConfig that uses viem's recoverAddress over a hashed message.
 * Smart-contract paths are exercised by overriding checkContractWalletSignature in
 * specific tests.
 */
function eoaOnlyConfig(): SiweConfig {
  return {
    verifyMessage: async (message: string, signature: string) => {
      const recovered = await recoverAddress({
        hash: hashMessage(message),
        signature: signature as `0x${string}`,
      });
      return getAddress(recovered);
    },
    hashMessage: (message: string) => hashMessage(message),
    getAddress: (address: string) => getAddress(address),
  };
}

function buildModule(opts: {
  env?: Record<string, string>;
  configs?: SiweConfigsByChain;
} = {}) {
  const env: Record<string, string> = {
    ALCHEMY_API_KEY: 'test',
    SIWE_ALLOWED_CHAIN_IDS: '1,11155111',
    SIWE_NONCE_TTL_MS: '300000',
    ...(opts.env ?? {}),
  };
  const configs: SiweConfigsByChain =
    opts.configs ?? new Map<number, SiweConfig>([[1, eoaOnlyConfig()], [11155111, eoaOnlyConfig()]]);
  return Test.createTestingModule({
    providers: [
      AuthService,
      { provide: ConfigService, useValue: { get: (key: string) => env[key] } },
      { provide: SIWE_CONFIGS, useValue: configs },
    ],
  }).compile();
}

const TEST_PK = '0x59c6995e998f97a5a0044966f0945389dc9e86dae88c7a8412f4603b6b78690d';
const TEST_ADDR = privateKeyToAccount(TEST_PK).address;

async function signedSiwe(opts: {
  address?: string;
  domain?: string;
  nonce: string;
  chainId?: number;
  uri?: string;
  expirationTime?: string;
  notBefore?: string;
  privateKey?: `0x${string}`;
}): Promise<{ message: string; signature: string }> {
  const account = privateKeyToAccount(opts.privateKey ?? TEST_PK);
  const msg = new SiweMessage({
    domain: opts.domain ?? 'namespace.ninja',
    address: opts.address ?? account.address,
    statement: 'Sign in to Avatar Service',
    uri: opts.uri ?? 'https://namespace.ninja',
    version: '1',
    chainId: opts.chainId ?? 1,
    nonce: opts.nonce,
    issuedAt: new Date().toISOString(),
    expirationTime: opts.expirationTime,
    notBefore: opts.notBefore,
  }).prepareMessage();
  const signature = await account.signMessage({ message: msg });
  return { message: msg, signature };
}
```

```markdown
## Auth & SIWE verification

The service authenticates avatar/header upload + delete requests using
[EIP-4361 Sign-In with Ethereum](https://eips.ethereum.org/EIPS/eip-4361)
via the [`@signinwithethereum/siwe`](https://www.npmjs.com/package/@signinwithethereum/siwe)
library (v4). Both EOA and smart-account wallets (EIP-1271, including EIP-6492
counterfactual) are supported natively through viem — no Ambire dependency.

### Flow

1. Client `POST /auth/nonce { address, scope }` → `{ nonce, expiresAt }`.
   `scope` is `"avatar"`, `"header"`, or `"avatar+header"` (default).
2. Client signs a SIWE message containing that nonce + the app's domain.
3. Client `POST` an avatar/header upload (multipart) or delete (JSON) with
   `siweMessage`, `siweSignature`, `address`, and **`domain`**.
4. Server asserts `domain === message.domain`, verifies the signature via v4
   (EOA recovery or EIP-1271/6492 RPC), checks chain allowlist + nonce TTL,
   flips the matching `used.<action>` flag, and on full consumption deletes
   the nonce record.

### `domain` — caller-asserted, no allowlist

The `domain` field is the DNS authority the SIWE message was signed for
(e.g. `app.example.com`, `localhost`). The server only checks that it equals
the `domain` line inside the SIWE message — it does **not** restrict which
domains are allowed. The service remains open: any app on any domain can
integrate without server-side enrolment.

### Grace period (T+0 → T+7 days)

After this version deploys, requests without `domain` are accepted with a
deprecation log; the server falls back to using the SIWE message's own domain
(binding becomes a no-op for that call). After 7 days, a follow-up PR sets
`SIWE_DOMAIN_REQUIRED=true` and rejects `MISSING_DOMAIN`. Update your
avatar SDK / ui-kit consumers before that window closes.

### Error codes

| Code | Meaning |
|---|---|
| `NONCE_NOT_FOUND` | No nonce for this address (or already consumed). |
| `NONCE_MISMATCH` | SIWE message embeds a nonce different from the stored one. |
| `DOMAIN_MISMATCH` | Caller `domain` ≠ `message.domain`. |
| `MISSING_DOMAIN` | Post-grace; caller omitted `domain`. |
| `MALFORMED_MESSAGE` | SIWE message could not be parsed. |
| `MESSAGE_NOT_YET_VALID` | `notBefore` is in the future. |
| `SIGNATURE_EXPIRED` | `expirationTime` is in the past, or nonce TTL elapsed. |
| `ADDRESS_MISMATCH` | Recovered signer ≠ `address` in the request body. |
| `INVALID_CHAIN_ID` | `chainId` not in `SIWE_ALLOWED_CHAIN_IDS`. |
| `SIGNATURE_VERIFICATION_FAILED` | Catch-all (EOA recovery failed, EIP-1271 returned false, etc.). |
| `UNAUTHORIZED` | Scope conflict or double-consumption of the same `used.<action>` flag. |

### Smart-account RPC dependency

EOA verification works fully offline (ecrecover). EIP-1271 (deployed) and
EIP-6492 (counterfactual) verification each issue one Alchemy RPC call.
If Alchemy is down, EOA users authenticate normally; smart-account users
get `SIGNATURE_VERIFICATION_FAILED`.
```
